# Sentra RBAC Admin Dashboard

## Overview

Sentra is a Full Stack Role-Based Access Control (RBAC) Admin Dashboard built with Django REST Framework and React. It provides secure JWT authentication, user management, role management, permission management, audit logging, and a responsive admin interface.

## Features

- JWT Authentication
- Role-Based Access Control (Admin, Manager, Viewer)
- User Management
- Role & Permission Management
- Audit Logs
- Excel Export
- Dark & Light Theme
- Responsive UI

## Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- Simple JWT

### Frontend
- React
- Vite
- Material UI
- React Router
- React Query
- Axios

## Installation

### Backend

cd backend

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver

### Frontend

cd frontend

npm install

npm run dev
